> Aplikasi E-Learning Kampus berbasis mobile yang dirancang untuk memudahkan mahasiswa dalam mengelola jadwal kuliah dan mengumpulkan tugas. Aplikasi ini mendukung pengunggahan foto bukti tugas langsung dari kamera/galeri serta menyimpannya secara lokal.

## ✨ Fitur Utama

- [x] Login/Register dengan validasi form
- [x] Daftar mata kuliah & jadwal kuliah menggunakan `FlatList`
- [x] Detail mata kuliah dengan navigasi Stack
- [x] Fitur pengumpulan tugas & ambil foto bukti via `expo-image-picker`
- [x] Simpan status tugas secara persisten dengan `@react-native-async-storage/async-storage`
- [x] Bottom Tab Navigation untuk navigasi antar layar

---

## 🛠️ Tech Stack

| Layer | Teknologi |
|-------|-----------|
| Framework | React Native + Expo |
| Navigation | React Navigation v6 (Stack + Bottom Tab) |
| Storage | @react-native-async-storage/async-storage |
| Device | expo-image-picker |
| Build | EAS Build (Expo Application Services) |
